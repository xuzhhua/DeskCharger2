# DeskCharger 2.0 设计文档

- 日期：2026-08-15
- 状态：已批准，实施中
- 技术栈：Tauri 2（Rust 后端）+ React 18 + TypeScript + Vite + Tailwind CSS
- 目标平台：Windows（x64）

> 摘要见评审稿：保留全局热键/定时提醒/托盘/自启/未保存提示；不做 CD-ROM/旧数据迁移/云同步。
> 架构原则：系统级能力一律在 Rust 后端，引擎不依赖前端存活；配置为类型化 JSON（tauri-plugin-store）。

## 模块
- hotkey：内置预设 + 用户自定义（组合键→命令/URL/内部功能），冲突检测，保存即时生效
- reminder：单次/每天/每周 + 重复次数与间隔；动作：通知/执行程序/系统动作/打开URL；一次性自动失效
- pomodoro：25/5/15 状态机、自定义、通知+可选自动续接、托盘显示
- clipboard：文本历史、去重、上限100、固定/搜索/回填
- monitor：CPU/内存/网络曲线、托盘CPU
- launcher：开始菜单+自定义目录索引、Ctrl+Space唤起、模糊匹配、白名单执行
- settings：亮/暗/跟随系统、自启、中/英、未保存提示
- tray：两态图标、菜单（打开/启动面板/番茄钟/监控/禁用/退出）

## 修正原版清单
`||`→`|`；`CString((LPCTSTR)ID)` 读非法内存；`GetBuffer` 越界；复制粘贴去重；魔法数字消除；中文外置 i18n；模块边界清晰化。

## 里程碑
M0 脚手架 → M1 热键+提醒 → M2 番茄钟+剪贴板 → M3 监控+快速启动 → M4 打磨打包

## 验收
托盘/单实例/热键/定时三类动作/番茄钟/剪贴板/监控/快速启动/主题/语言可用；`cargo test` 与前端测试通过；`tauri build` 可出包。
